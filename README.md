# SUPER NIKOLIO — Android TV · версия 1.0

Самостоятельная офлайн-аркада для телевизора TCL Android TV / Google TV (16:9), управление штатным D-pad пультом.

## Содержимое

- `app/src/main/assets/index.html` — интерфейс и сцены
- `app/src/main/assets/game.js` — игровой движок с фиксированным шагом 60 Гц, генерация уровней, сцены, анимации, музыкальный синтезатор
- `app/src/main/assets/img` — отдельные спрайты из присланных изображений
- `app/src/main/java/com/supernikolio/tv/MainActivity.java` — ТВ-оболочка на Android WebView
- `.github/workflows/build-apk.yml` — автоматическая сборка при загрузке в GitHub
- `ГОТОВЫЙ_BUILD_APK_YML.txt` — *видимая* копия workflow для ручного создания файла через GitHub, если браузер не загружает скрытую папку `.github`.

## Управление пультом

- В игре: `←`/`→` идти, `↑` прыгнуть, `↓` присесть, `OK` бросить гранат (перезарядка 0.31 с), `Назад` пауза.
- В меню: `↑`/`↓` выбор, `OK` подтвердить, `Назад` вернуться/снять паузу.
- Для прыжка действует небольшой буфер ввода и «coyote time», чтобы прыжки оставались комфортными на телевизоре.
- Три сердца, две контрольные точки на уровне, прохождение до флагов и сохранение последнего открытого уровня.

## Семь уровней

1. Площадь Республики
2. Северный проспект
3. Каскад
4. Парламентский парк
5. Старый Ереван
6. Дорога к Арарату
7. Финальный путь

Короткие уровни с различными тематическими фонами и контролируемой процедурной вариативностью препятствий. Проверяемая горизонтальная геометрия: разрывы дороги уже максимально достижимого прыжка, вертикальные платформы не выше высоты прыжка. Продолжительность зависит от темпа игрока, обычно несколько минут.

## Музыка и звуки

Оригинальная музыка создаётся средствами Web Audio — медленная мелодия и сменяющиеся аккорды, без лицензируемых звуковых файлов или сетевых вызовов. Эффекты отдельно озвучивают прыжки, приземления, выстрелы, попадания, сбор еды, здоровье, контрольные точки, паузу, победу и поражение. Музыку и эффекты можно независимо отключать в меню и на паузе. Некоторые телевизоры разрешают звуки только после первого нажатия кнопки.

## GitHub Actions — автоматическая сборка

1. Создайте **новый приватный репозиторий** (в проекте используются портреты, присланные пользователем).
2. Загрузите **содержимое** этой папки (НЕ ZIP файлом). Сохраняйте структуру `app`, `build.gradle`, `settings.gradle`, `gradle.properties`.
3. В Finder macOS скрытая папка `.github` показывается сочетанием `⌘ ⇧ .`. Если Chrome не загружает скрытую папку: просто создайте через GitHub **Add file → Create new file** путь `.github/workflows/build-apk.yml` и вставьте текст из видимого `ГОТОВЫЙ_BUILD_APK_YML.txt`.
4. После `Commit changes` workflow запустится сам (вкладка **Actions**). После успешного запуска скачайте **Artifacts → SUPER-NIKOLIO-AndroidTV-APK**.
5. В ZIP артефакте будет `app-debug.apk`. Перенесите его на TCL и установите. При обновлении подписанного другим debug-ключом APK может потребоваться удалить старую версию.

Сборка из Android Studio: **Build → Build APK(s)**, результат `app/build/outputs/apk/debug/app-debug.apk`.

## Что проверено / не проверено

Браузерные дымовые тесты Chromium: старт, движение, прыжок, выстрел, пауза, возвращение с паузы и отсутствие JavaScript-ошибок. Android SDK в авторской среде отсутствует: компиляция APK и тест на физическом TCL должны быть выполнены отдельно.

**Это собственная аркада, а не копия Mario.** Мир и мелодия оригинальные, персонажи основаны на предоставленных пользователем материалах; игровая история и финальная надпись являются сатирической выдумкой, а не фактическим политическим утверждением.
